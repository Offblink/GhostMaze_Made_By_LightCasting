《GhostMaze：幽灵迷宫》 游戏说明书


1. 游戏背景
玩家置身于一个充满神秘氛围的恐怖环境中，需要在不被恐惧吞噬的情况下，寻找出路，逃离这个被诅咒的地方。

2. 游戏目标
主要目标：通过所有关卡（共3个关卡）。
当前目标：在当前关卡中寻找钥匙并开门，前往下一关。

3. 界面说明 (HUD)
游戏屏幕上方或显眼位置将显示以下状态信息：
生命：显示玩家当前的生命值状态。
钥匙：显示当前关卡收集进度。玩家需要找到所有钥匙才能开门。
地图：显示地图获取状态。初始状态为“未获取”，玩家需在游戏过程中寻找地图道具。
关卡 (1/3)：显示当前进度。游戏共有3个关卡，目前处于第1关。

4. 操作指南
游戏主要通过屏幕下方的虚拟按钮进行交互：
疾跑：点击或长按此按钮，角色将进行快速移动，用于逃离危险或加快探索速度。
开门：当玩家靠近门且拥有对应钥匙时，点击此按钮可打开房门进入下一关。
暂停 (II)：点击屏幕上的暂停图标，游戏将停止运行。
*暂停菜单*：屏幕将显示“游戏暂停”及“点击屏幕继续”提示，点击任意屏幕区域即可返回游戏。

5. 游戏提示
优先寻找钥匙：每个关卡都需要钥匙才能通过，请仔细探索地图角落。
注意生命值：时刻关注生命状态，避免死亡导致游戏重来。
利用地图：地图是重要的辅助道具，获取后能更清晰地规划逃跑路线。
